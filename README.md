### 🚀 Featured projects
- **[ChopDash](https://github.com/kd7-gif/chopdash)** · [Live demo](https://chopdash-demo.netlify.app):
  a food delivery platform with three apps in one: customers order, restaurants manage orders
  from a kitchen dashboard, and riders deliver from a phone-first app. Every status change is
  tracked live over WebSockets. Dish and restaurant recommendations are learned from order
  history and beat a popularity baseline (69% vs 54% top-1 hit rate). Built with React,
  Express and PostgreSQL, with Paystack payments and 48 API tests.
- **[Arede-Homes Demo](https://arede-store-demo.netlify.app)**: a deployed e-commerce store for a home and
  appliances business. Built with React, Node.js, Express and MySQL, with customer
  accounts, Paystack checkout, delivery and pickup options, and an admin panel for
  managing products and orders.
- **[Nigerian Drought Forecast Platform](https://github.com/kd7-gif/Nigerian-drought-prediction)**:
  a full-stack platform forecasting drought for all 37 Nigerian states up to six months ahead.
  GRU and Transformer models in PyTorch, served through FastAPI to a React and Express dashboard.
  The best model reached R² 0.866. Built as my final-year project.
